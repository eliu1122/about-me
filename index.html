SEC Simplifier

Grounded Q&A over SEC EDGAR filings
  • Python
  • RAG
  • Chroma
  • BM25
  • LLM APIs
  • pytest

Ask a plain-English question about any US public company and get an answer built only from that company’s SEC filings — on-demand EDGAR ingestion, table-aware chunking, and hybrid BM25 + vector retrieval, with no RAG framework underneath. Every answer cites its filing, every quote is checked against the original text, and when the evidence isn’t there it says “not disclosed” rather than guessing. I built the eval harness alongside it, which is how I found that abstention thresholds tuned on one company don’t generalize to the next.
